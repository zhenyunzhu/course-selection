# 03 · 接口清单

> 只列主链路。`/internal/**` 是服务间调用，不经过网关、不对外。

## 对外接口（经网关 8088）

| # | 接口 | 谁调 | 入参 | 出参 | 读表 | 写表 / 缓存 | 失败码 |
|---|---|---|---|---|---|---|---|
| 1 | `POST /api/auth/login` | 公开 | `studentId`、`name` | `token`、`studentId`、`name` | 无 | Redis `token:{token}` = `studentId\|name`，24h | `1001` |
| 2 | `GET /api/courses` | 需登录 | 无 | 课程列表 | `t_course` | 无 | `1010` |
| 3 | `GET /api/courses/{id}` | 需登录 | `id`（Path） | 课程详情 | `t_course` | 无 | `1010`、`2001` |
| 4 | `GET /api/courses/{id}/classes` | 需登录 | `id`（Path） | 教学班列表（含余量） | `t_class` | 无 | `1010` |
| 5 | `POST /api/enrollments` | 需登录 | Header `X-Idempotent-Token`；Body `classId` | `enrollNo`、`courseName`、`credit`、`teacher` | `t_enrollment`（查重、学分、冲突、先修） | `t_enrollment` insert；`t_outbox_message` insert；**跨服务**：`t_class.remain-1`、`t_capacity_reserve` insert | `3001`、`3002`、`3003`、`3004`、`2003`、`2000` |
| 6 | `DELETE /api/enrollments/{enrollNo}` | 需登录 | `enrollNo`（Path） | 无 | `t_enrollment` | `t_enrollment` status 1→0；`t_outbox_message` insert；**跨服务**：`t_class.remain+1` | `3005`、`2000` |
| 7 | `GET /api/enrollments/my` | 需登录 | 无 | 我的课表 | `t_enrollment` | 无 | `1010` |

## 内部接口（course，仅服务间）

| # | 接口 | 调用方 | 作用 | 表 |
|---|---|---|---|---|
| 1 | `GET /internal/classes/{classId}` | enroll | 一次拿全教学班信息（课程名/学分/先修/排课） | `t_class`、`t_course`、`t_class_schedule` |
| 2 | `POST /internal/capacity/reserve` | enroll | Try：预占容量 | `t_class` update、`t_capacity_reserve` insert |
| 3 | `POST /internal/capacity/{id}/confirm` | enroll | Confirm：预占转正式 | `t_capacity_reserve` CAS 0→1 |
| 4 | `POST /internal/capacity/{id}/cancel` | enroll | Cancel：补偿（只处理预占中） | CAS 0→2 + `t_class` 回补 |
| 5 | `POST /internal/capacity/{id}/release` | enroll | Release：退课（处理已确认） | CAS 1→2 + `t_class` 回补 |
| 6 | `POST /internal/capacity/release-expired` | enroll 对账 / 定时任务 | 释放超时预占 | CAS 0→3 + 回补 |

## 失败码表

| 码 | 含义 | 常见触发 |
|---|---|---|
| `1001` | 参数不合法 | 缺 `X-Idempotent-Token`、`classId` 为空、类型不对 |
| `1010` | 未登录 / token 失效 | 网关卡住，或 Redis 里 token 过期 |
| `2000` | 系统繁忙 | 下游超时、未捕获异常 |
| `2003` | 容量不足 | 教学班 `remain = 0` |
| `3001` | 重复选课 / 重复提交 | 同课程已选，或同一个幂等 token 重放 |
| `3002` | 超学分上限 | 已选 + 本课 > 30 |
| `3003` | 时间冲突 | 与已选课程同一天且节次相交 |
| `3004` | 未满足先修 | 先修课没有有效选课记录 |
| `3005` | 选课记录不存在 | 退课单号错，或已退过 |

## 一次选课会碰到的表（面试必答）

```
读：t_enrollment（查重/学分/冲突/先修）
    t_class、t_course、t_class_schedule（跨服务一次调用拿全）

写：t_class            ← remain = remain - 1（条件更新）
    t_capacity_reserve ← 插一条 status=0 的预占
    t_enrollment       ← 插选课单
    t_outbox_message   ← 插待投递消息

缓存：Redis idem:enroll:{token}（5 分钟）
      Redis token:{token}（24 小时，登录态）
```
